📖 Read this first

Goal. Lab 4 adds a formal, auditable "what did IT Staff actually do" record (ActionTaken) under each Ticket, makes RESOLVED mean something by blocking that transition until at least one such record exists, and gives all three roles a landing-page dashboard summarizing their own operational picture without duplicating the existing Ticket Queue / My Tickets screens. Every Lab 1-3 capability keeps passing unchanged.

Key decisions. The resolution gate (D-02) checks only that a qualifying record <em>exists</em> — never that its <code>Result</code> equals <code>RESOLVED</code> — because a ticket can legitimately close after a final action whose result was <code>ESCALATED</code> or <code>NO_ACTION_NEEDED</code>, and because an editable record makes "the most recent Result" an unstable thing to gate on. Dashboards are aggregate-only (BR-13): every metric is a database <code>count</code>/<code>groupBy</code>, never a full list fetched and counted in application code — this plan widens <code>Ticket.ownerId</code>'s index specifically so the two staff-dashboard metrics that filter on it don't table-scan. Creating or editing an Action Taken never touches <code>Ticket.updatedAt</code> (D-06), matching how Comment/InternalNote already behave. The plan also had to fix a real pre-existing gap surfaced along the way: <code>staffRouter</code> currently gates the entire <code>/staff/*</code> namespace to <code>IT_STAFF</code> only, which would have silently 403'd every Administrator out of the IT Staff Dashboard the spec explicitly makes their landing page — Task 12 widens that gate.

Global Constraints

  • No Zod, no axios, no react-query anywhere in this repo — every validator is a hand-written {ok,value}|{ok,errors} function (see server/src/validators/createTicketRequest.ts), every API client function is a bare fetch with credentials: 'include' (see client/src/api/comments.ts).
  • Error envelope is always { error: { code, message, fieldErrors, correlationId } } (server/src/middleware/errorEnvelope.ts) — never invent a different shape.
  • Ticket.version, Ticket.requesterResolutionConfirmedAt, Ticket.resolutionSummary stay untouched (D-01) — no task in this plan reads or writes them.
  • No optimistic-concurrency / If-Match headers on any Lab 4 endpoint (D-04) — duplicate-submit protection is client-side only (disable the submit control while a request is in flight).
  • Creating or editing an ActionTaken never updates Ticket.updatedAt (D-06, BR-14).
  • The FR-06/BR-09 resolution gate checks only that count(ActionTaken) >= 1, never a specific Result value (D-02).
  • Every dashboard metric is a database count/groupBy, never a full-list fetch counted in application code (BR-13).
  • Package manager is npm (root, server/, client/ all have package-lock.json); server tests run via npm test --prefix server (vitest run), client tests via npm test --prefix client, e2e via npm run test:e2e from repo root.

Review Focus

  • **A status-PATCH request that targets RESOLVED on a Ticket whose only ActionTaken was later made irrelevant by nothing (i.e. any qualifying record at all, including one with Result: ESCALATED)** — a reasonable implementer might be tempted to filter by Result: 'RESOLVED' since the target status is also called RESOLVED; the spec (D-02) explicitly forbids this and Task 6's tests pin both the accept and the wrong-filter-would-reject cases.
  • **followUpRequired toggled from true to false on an edit, with the request body still carrying the old followUpNote text** — BR-05/AC-07 require the stored note be cleared regardless of what the client sends; Task 3's validator tests and Task 4's route tests both pin this.
  • **An Action Taken create/edit attempt against a Ticket already in CLOSED or CANCELLED** — BR-08 locks this the same way owner/priority/status already lock in staff/tickets.ts; Task 4's tests pin the 409 TICKET_LOCKED response and that no row is written.
  • A Requester dashboard or ticket-scoped Action Taken request for a Ticket that isn't the caller's own — BR-12/AC-02 require the dashboard to be scoped from the session, never a client-supplied id; Task 5 and Task 12's tests pin that a second Requester's data never leaks into the response.
  • **An Action Date/Time (actionAt) submitted in the future** — BR-07; easy to omit since none of the existing Comment/InternalNote/Attachment validators have a temporal field to copy from. Task 3's validator tests pin both a same-instant boundary (allowed) and a future instant (rejected).

import { describe, it, expect, beforeAll, beforeEach } from 'vitest';
import { prisma } from '../../src/prisma';
import { truncateTicketTables } from '../helpers/resetDb';
import { generateTicketNumber } from '../../src/services/ticketNumber';

describe('ActionTaken model (Lab 4 schema)', () => {
  let requesterId: string;
  let staffId: string;
  let staff2Id: string;
  let categoryId: number;

  beforeAll(async () => {
    const requester = await prisma.user.findFirstOrThrow({ where: { role: 'REQUESTER' } });
    const staff = await prisma.user.findFirstOrThrow({ where: { role: 'IT_STAFF' }, orderBy: { email: 'asc' } });
    const staff2 = await prisma.user.findFirstOrThrow({
      where: { role: 'IT_STAFF', email: { not: staff.email } },
      orderBy: { email: 'asc' },
    });
    requesterId = requester.id;
    staffId = staff.id;
    staff2Id = staff2.id;
    categoryId = (await prisma.category.findFirstOrThrow({ where: { isActive: true } })).id;
  });

  beforeEach(async () => {
    await truncateTicketTables();
  });

  async function createTicket() {
    const ticketNo = await generateTicketNumber(prisma, new Date().getUTCFullYear());
    return prisma.ticket.create({
      data: {
        ticketNo, summary: 'Printer offline', description: 'Front-desk printer shows offline.',
        requestedPriority: 'MEDIUM', itPriority: 'MEDIUM', requesterId, categoryId,
      },
    });
  }

  it('creates an ActionTaken with performedById set and lastEditedById null', async () => {
    const ticket = await createTicket();
    const action = await prisma.actionTaken.create({
      data: {
        ticketId: ticket.id, performedById: staffId, actionAt: new Date(),
        description: 'Power-cycled the printer and reseated the network cable.',
        result: 'RESOLVED', followUpRequired: false,
      },
    });
    expect(action.performedById).toBe(staffId);
    expect(action.lastEditedById).toBeNull();
    expect(action.result).toBe('RESOLVED');
  });

  it('allows lastEditedById to differ from performedById on edit', async () => {
    const ticket = await createTicket();
    const created = await prisma.actionTaken.create({
      data: {
        ticketId: ticket.id, performedById: staffId, actionAt: new Date(),
        description: 'Initial diagnosis.', result: 'PENDING_FOLLOW_UP',
        followUpRequired: true, followUpNote: 'Waiting on replacement toner cartridge.',
      },
    });
    const edited = await prisma.actionTaken.update({
      where: { id: created.id },
      data: { lastEditedById: staff2Id, description: 'Cartridge replaced, confirmed printing.' },
    });
    expect(edited.performedById).toBe(staffId);
    expect(edited.lastEditedById).toBe(staff2Id);
  });

  it('does not touch Ticket.updatedAt when an ActionTaken is created (D-06/BR-14)', async () => {
    const ticket = await createTicket();
    await prisma.actionTaken.create({
      data: {
        ticketId: ticket.id, performedById: staffId, actionAt: new Date(),
        description: 'No-op check.', result: 'NO_ACTION_NEEDED', followUpRequired: false,
      },
    });
    const reloaded = await prisma.ticket.findUniqueOrThrow({ where: { id: ticket.id } });
    expect(reloaded.updatedAt.getTime()).toBe(ticket.updatedAt.getTime());
  });

  it('writes an ACTION_TAKEN_ADDED TicketEvent row (schema accepts the new enum value)', async () => {
    const ticket = await createTicket();
    await prisma.ticketEvent.create({
      data: { ticketId: ticket.id, actorId: staffId, eventType: 'ACTION_TAKEN_ADDED' },
    });
    const events = await prisma.ticketEvent.findMany({ where: { ticketId: ticket.id } });
    expect(events).toHaveLength(1);
    expect(events[0].eventType).toBe('ACTION_TAKEN_ADDED');
  });
});

export type { FieldError };

const RESULTS = ['RESOLVED', 'ESCALATED', 'NO_ACTION_NEEDED', 'PENDING_FOLLOW_UP'] as const;

  | { ok: true; value: ValidatedActionTakenRequest }
  | { ok: false; errors: FieldError[] };

function validate(body: Record<string, unknown>): ValidationResult {
  const errors: FieldError[] = [];

  let actionAt: Date | null = null;
  if (typeof body.actionAt !== 'string') {
    errors.push({ field: 'actionAt', message: 'actionAt is required and must be an ISO 8601 timestamp' });
  } else {
    const parsed = new Date(body.actionAt);
    if (Number.isNaN(parsed.getTime())) {
      errors.push({ field: 'actionAt', message: 'actionAt must be a valid ISO 8601 timestamp' });
    } else if (parsed.getTime() > Date.now()) {
      // BR-07: may not be set in the future. A same-instant value is allowed (boundary is
      // inclusive) -- only a strictly-later timestamp is rejected.
      errors.push({ field: 'actionAt', message: 'actionAt may not be in the future' });
    } else {
      actionAt = parsed;
    }
  }

  const rawDescription = typeof body.description === 'string' ? body.description.trim() : '';
  if (typeof body.description !== 'string' || rawDescription.length < 1 || rawDescription.length > 2000) {
    errors.push({ field: 'description', message: 'description is required, 1-2000 characters' });
  }

  const result = body.result;
  if (typeof result !== 'string' || !(RESULTS as readonly string[]).includes(result)) {
    errors.push({ field: 'result', message: `result must be one of ${RESULTS.join(', ')}` });
  }

  const followUpRequired = body.followUpRequired === true;
  if (body.followUpRequired !== undefined && typeof body.followUpRequired !== 'boolean') {
    errors.push({ field: 'followUpRequired', message: 'followUpRequired must be a boolean' });
  }

  // BR-05: required and non-empty when true, cleared to empty (null, stored) when false --
  // computed after followUpRequired so a bad followUpRequired doesn't also produce a
  // misleading followUpNote error.
  let followUpNote: string | null = null;
  if (followUpRequired) {
    const rawNote = typeof body.followUpNote === 'string' ? body.followUpNote.trim() : '';
    if (rawNote.length < 1 || rawNote.length > 1000) {
      errors.push({ field: 'followUpNote', message: 'followUpNote is required and non-empty when followUpRequired is true' });
    } else {
      followUpNote = rawNote;
    }
  }

  let attachmentNotes: string | null = null;
  if (body.attachmentNotes !== undefined && body.attachmentNotes !== null) {
    const raw = typeof body.attachmentNotes === 'string' ? body.attachmentNotes.trim() : '';
    if (typeof body.attachmentNotes !== 'string' || raw.length > 500) {
      errors.push({ field: 'attachmentNotes', message: 'attachmentNotes must be 500 characters or fewer' });
    } else {
      attachmentNotes = raw.length > 0 ? raw : null;
    }
  }

  if (errors.length > 0) {
    return { ok: false, errors };
  }

  return {
    ok: true,
    value: {
      actionAt: actionAt as Date,
      description: rawDescription,
      result: result as ActionResult,
      followUpRequired,
      followUpNote,
      attachmentNotes,
    },
  };
}

staffActionsRouter.post<{ id: string }>('/', async (req, res, next) => {
  try {
    const validated = validateCreateActionTakenRequest(req.body ?? {});
    if (!validated.ok) throw new ValidationHttpError(validated.errors);

    const ticket = await findTicketOrThrow(req.params.id);
    if (TERMINAL_STATUSES.includes(ticket.status as never)) {
      throw new HttpError(409, 'TICKET_LOCKED', 'Cannot record an Action Taken on a Closed or Cancelled ticket');
    }

    const { actionAt, description, result, followUpRequired, followUpNote, attachmentNotes } = validated.value;
    const created = await prisma.$transaction(async (tx) => {

        data: {

          followUpRequired, followUpNote, attachmentNotes,
        },
        include: ACTION_INCLUDE,
      });
      await tx.ticketEvent.create({
        data: { ticketId: ticket.id, actorId: req.user!.id, eventType: 'ACTION_TAKEN_ADDED', payload: { actionId: action.id } },
      });
      return action;
    });

    res.status(201).json(serializeAction(created));
  } catch (error) {
    next(error);
  }
});

        data: { ticketId: ticket.id, actorId: req.user!.id, eventType: 'ACTION_TAKEN_UPDATED', payload: { actionId: action.id } },

// server/src/services/dashboardMetrics.ts
import { prisma } from '../prisma';
import type { TicketStatus } from './ticketStatusTransitions';

export const ALL_STATUSES: TicketStatus[] = [
  'NEW', 'OPEN', 'IN_PROGRESS', 'WAITING_FOR_REQUESTER', 'RESOLVED', 'CLOSED', 'REOPENED', 'CANCELLED',
];
const ALL_PRIORITIES = ['LOW', 'MEDIUM', 'HIGH', 'URGENT'] as const;
const ALL_ROLES = ['REQUESTER', 'IT_STAFF', 'ADMINISTRATOR'] as const;
const NON_TERMINAL_STATUSES = ALL_STATUSES.filter((s) => s !== 'CLOSED' && s !== 'CANCELLED');
const RECENT_LIMIT = 5;

interface RecentTicketSummary {
  id: string;
  ticketNo: string;
  summary: string;
  status: string;
  updatedAt: Date;
}

const RECENT_SELECT = { id: true, ticketNo: true, summary: true, status: true, updatedAt: true } as const;

// Three separate zero-fill helpers, not one generic one: Prisma's groupBy result type differs
// per `by` field, so a single generic helper would need an unsafe cast at each call site.
function zeroFillStatusCounts(rows: { status: string; _count: { status: number } }[]): Record<string, number> {
  const result: Record<string, number> = Object.fromEntries(ALL_STATUSES.map((s) => [s, 0]));
  for (const row of rows) result[row.status] = row._count.status;
  return result;
}

function zeroFillPriorityCounts(rows: { itPriority: string; _count: { itPriority: number } }[]): Record<string, number> {
  const result: Record<string, number> = Object.fromEntries(ALL_PRIORITIES.map((p) => [p, 0]));
  for (const row of rows) result[row.itPriority] = row._count.itPriority;
  return result;
}

function zeroFillRoleCounts(rows: { role: string; _count: { role: number } }[]): Record<string, number> {
  const result: Record<string, number> = Object.fromEntries(ALL_ROLES.map((r) => [r, 0]));
  for (const row of rows) result[row.role] = row._count.role;
  return result;
}

export async function getRequesterDashboard(requesterId: string) {
  const [statusRows, recentTickets] = await Promise.all([
    prisma.ticket.groupBy({ by: ['status'], where: { requesterId }, _count: { status: true } }),
    prisma.ticket.findMany({
      where: { requesterId }, orderBy: { updatedAt: 'desc' }, take: RECENT_LIMIT, select: RECENT_SELECT,
    }),
  ]);
  return {
    statusCounts: zeroFillStatusCounts(statusRows),
    recentTickets: recentTickets as RecentTicketSummary[],
  };
}

export async function getStaffDashboard(currentUserId: string, includeUserCounts: boolean) {
  const [unassignedCount, ownedByMeCount, statusRows, priorityRows, recentTickets, userRoleRows] = await Promise.all([
    prisma.ticket.count({ where: { ownerId: null, status: { in: NON_TERMINAL_STATUSES as never[] } } }),
    prisma.ticket.count({ where: { ownerId: currentUserId, status: { in: NON_TERMINAL_STATUSES as never[] } } }),
    prisma.ticket.groupBy({ by: ['status'], _count: { status: true } }),
    prisma.ticket.groupBy({ by: ['itPriority'], _count: { itPriority: true } }),
    prisma.ticket.findMany({ orderBy: { updatedAt: 'desc' }, take: RECENT_LIMIT, select: RECENT_SELECT }),
    includeUserCounts
      ? prisma.user.groupBy({ by: ['role'], where: { isActive: true }, _count: { role: true } })
      : Promise.resolve(null),
  ]);

  return {
    unassignedCount,
    ownedByMeCount,
    statusCounts: zeroFillStatusCounts(statusRows),
    priorityCounts: zeroFillPriorityCounts(priorityRows),
    recentTickets: recentTickets as RecentTicketSummary[],
    userCounts: userRoleRows ? zeroFillRoleCounts(userRoleRows) : null,
  };
}
